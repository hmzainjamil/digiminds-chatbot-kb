# Deployment guide status

## Status

This file is a proposal only. No deployment path, provider account, website widget, vector database, CRM, calendar, messaging channel, or analytics integration is configured or verified by this repository. Do not follow the former provider-specific steps, cost estimates, model choices, or timing estimates as current instructions.

## Required design and approval work

Before choosing a deployment path, the accountable product and data owners should:

1. Approve the knowledge content and provide evidence for public claims, prices, guarantees, partnerships, and competitor statements.
2. Classify personal, client, and confidential data; remove content that should not be sent to a model or stored in retrieval.
3. Select providers and review current documentation, account terms, data processing, retention, regional handling, and access controls.
4. Define consent, notice, opt-out, deletion, human handoff, and incident processes.
5. Specify retrieval source attribution, refusal behavior, and safeguards against unsupported claims.
6. Build and test the application separately, including a grounded evaluation set, privacy and security checks, failure handling, and human review.
7. Verify production behavior, access controls, logging, rollback, and monitoring before public release.

## Evidence boundary

No runtime, dependency manifest, deployment file, test suite, integration credential, or release record is present in the reviewed tree. A successful PDF build or completed checklist would not prove chatbot deployment or production readiness.
